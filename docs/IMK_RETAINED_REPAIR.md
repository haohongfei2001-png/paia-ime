## Actual use and limits

The input-method menu offers “Retain next composition for segment repair” only for an idle eligible engine session. It affects exactly the next composition; it is not saved in preferences. Space/numbers confirm genuine candidates into the owned mark. Once every segment is confirmed, Option+Left/Right navigates actual engine anchors. In the non-key repair panel, letters/apostrophe edit only the spelling draft; ordinary arrows/Home/End/Backspace/Delete edit that draft. Space or Search explicitly computes alternatives, without per-letter decoding. Arrows/Page Up/Down navigate displayed choices; 1–5/Space chooses from that exact page and opens full review. Apply only updates marked composition. A separate menu action commits fully confirmed Chinese through the engine and existing dispatcher. Return always keeps its original raw-input meaning, including while reviewing. Escape cancels only the repair first; a later fresh Escape cancels composition. No system-wide shortcut or physical delivery is assumed.

Partial confirmation, unverified filters and unsupported resources refuse repair without a spelling flush. The explicit retained lane refuses punctuation/uppercase that could implicitly commit. A hypothetical unexpected engine commit is consumed inside the bridge and rejected before a host effect; the original in-memory recovery remains available and no result is replayed. Normal non-retained punctuation/input is unchanged. Search may be incomplete; engine traversal order is not a new quality rank. This bounded native C++ call is synchronous and cannot be safely timed out/cancelled by a Swift Task. The 200-word overflowing UI case is a final test refinement, separate from the 128-word engine/host cases.

The native panel needs at least a 500×514-point usable screen and refuses presentation below that bound; an unseen review cannot authorize Apply. Native content renders do not prove installed placement, physical navigation, assistive-technology usability, live ownership or tail latency. Fully confirmed replay is the supported G01 domain; partial-confirmation and cross-filter mappings can remain unsupported. Only the existing C0 owned-mark protocol contract is used, without C2/C3 surrounding or selected-host text reads.
