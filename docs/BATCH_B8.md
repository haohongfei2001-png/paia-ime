## Implementation and native verification

- Separate ordinary `text(String)` from explicit physical control keysyms. Unicode/multi-scalar events pass through AppKit when idle; while composing they receive a typed pre-mutation refusal.
- At every raw caret before the suffix, including zero, refuse ASCII punctuation/uppercase before engine mutation. Lowercase spelling, the apostrophe delimiter, explicit candidate selection and physical controls retain real engine paths.
- A refusal preserves the complete snapshot, generation, candidate references and timing. It performs no host apply or marked-text rewrite. The native host shows a wrapping warning with explicit Return/Escape recovery; it does not retry or move the caret. Obsolete refusal text is cleared without replacing newer status messages.
- Pending commit effects cannot be treated as refusal/passthrough states. Host apply latches against synchronous reentry and checks the precomputed exact native result plus session/generation/window/focus after each write. On ownership loss it retires without further native mutation or replay of a reserved insertion.
- Engine-returned unhandled events reach AppKit only after successful apply, with the same current dispatcher and no remaining engine/native composition. Command/Option and literal-mode cancellation also require verified native state and event identity before AppKit continuation. Replacement/factory callbacks cannot revive or overwrite a newer owner.

Coverage included the initial regressions, exact no-op at start/middle/confirmed composition, candidate identity, pending effects, idle/literal Unicode, explicit controls, refusal callback reentry, native write callback ownership loss, repeated effect delivery and recursive marked application. Later ownership findings and their expanded coverage are recorded above; the initial green is not final acceptance. Both actual refusal captures were opened and independently reviewed; the marked input and complete recovery text are readable.

The minimum safety contract is pre-mutation, visible refusal of unsupported actions while retaining the complete raw input, caret, candidates and native marked document. No silent suffix loss, automatic move-to-end, fabricated engine candidate or premature effect reservation is acceptable. Full middle-punctuation/Unicode composition semantics remains an open gate, not a completed feature. A future compound insertion contract needs explicit engine/literal provenance, confirmed-segment preservation, commit-drain ownership and safe partial-host-write handling. The callback guards are not an atomic compare-and-swap against unannounced document mutation during native calls and cannot undo an already issued insertion.

No new resources, dictionaries, fonts, service, input-source installation or persistent user data. Probe traces contain authored synthetic text only. These are ENGINE_NATIVE and APPKIT_HOST checks in an uninstalled lab, not physical keyboard, installed-client, language-quality or visible-latency certification. Source review alone is not proof of a failing runtime path.
